# SolePro Finance Assistant

SolePro Finance Assistant — это приложение для ведения учёта доходов от предпринимательской деятельности по ИП.
Проект включает:

- **Desktop-приложение на PyQt6**
- **Telegram-бот** для управления финансами

---

## Функции

- Учет доходов и расходов
- Работа с контрагентами
- Статистика по периодам
- Экспорт данных в CSV/Excel

---

## Установка

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/yourusername/solepro-finance-assistant.git

2. Установите зависимости:
pip install -r requirements.txt

3. Запустите приложение:
python main.py
