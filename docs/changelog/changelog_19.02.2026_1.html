Этапный рефакторинг desktop-архитектуры, усиление DIP/SOLID и стабилизация тестового контура
Дата: 19.02.2026
Версия: 1.3.11rc1
Статус: Stable Refactor
Фокус: MVC / OOP / DRY / SOLID

1. Резюме релиза

Выполнен крупный последовательный рефакторинг с минимальным риском поломок: ответственность DesktopController разложена по координаторам и сервисам, bootstrap desktop-приложения декомпозирован на builder-методы и контракты, расширен и стабилизирован тестовый контур. Дополнительно выполнена очистка проблемного mojibake в desktop-контроллере.

Controller -> Coordinators Export Service Extraction Protocol-based DIP Bootstrap SRP Tests Hardening UTF-8 Cleanup

2. Ключевые архитектурные изменения

Desktop Controller

  • Переведен на координаторы транзакций/контрагентов.
  • Экспорт выделен в отдельный сервис и инъецируется извне.
  • Убраны лишние use-case зависимости из конструктора.
  • Введены единые helper-механизмы обработки ошибок и перезагрузки.

Desktop Bootstrap

  • Введены протоколы контрактов и вынесены в отдельный модуль contracts.py.
  • Создание controller/coordinator/export/app/window вынесено в отдельные builder-методы.
  • Выполнена стандартизация сообщений/кодов выхода и логирования.
  • Добавлена инъекция log_writer для тестируемости и гибкости.

Качество и стабильность

  • Добавлены и расширены unit/smoke тесты контроллеров, координаторов и entrypoints.
  • Хрупкие ассерты ошибок заменены на устойчивые проверки причин.
  • Сохранено обратимо-предсказуемое поведение для UI-сценариев.
  • По каждому подэтапу выполнялся py_compile и регрессионный pytest.

3. Финальные шаги (последний цикл)

3.1 Вынос контрактов

Протоколы DesktopBootstrap вынесены из application.py в src/solepro/presentation/desktop/contracts.py, что снизило связанность и упростило сопровождение.

3.2 Typed stubs в entrypoints-тестах

SimpleNamespace заменены на явные typed stubs (_SessionManagerStub, _SentinelContainerStub, _QtAppSpy, _MainWindowSpy и др.).

3.3 Очистка mojibake в MainController

Файл main_controller.py переписан в корректном UTF-8 с сохранением поведения. Исправлены сообщения ошибок и локальная структурная документация.

5. Верификация

  • Синтаксис: python -m py_compile для затронутых модулей.
  • Целевые проверки: pytest src/tests/test_entrypoints.py -q, pytest src/tests/test_main_controller.py -q.
  • Полный регресс: pytest src/tests -q (зелёный прогон).

6. Итог

Рефакторинг завершен с сохранением функциональности и усилением архитектурной целостности. Desktop-слой приведен к более строгому MVC/OOP/DIP стилю, тестовый контур расширен и стабилизирован, база для дальнейшего развития подготовлена.
