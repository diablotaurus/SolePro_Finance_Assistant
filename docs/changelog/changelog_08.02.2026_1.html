Архитектурная революция

Выполнен радикальный рефакторинг с полной перестройкой архитектуры проекта. Внедрена Clean Architecture с разделением на доменный слой, слой приложения, инфраструктурный и презентационный слои. Проект подготовлен для промышленной эксплуатации с поддержкой Docker, PostgreSQL и профессиональными инструментами разработки.

Внимание: Радикальные изменения

Данный рефакторинг полностью меняет структуру проекта. Все существующие модули будут заменены. База данных переходит на SQLAlchemy с поддержкой PostgreSQL. Архитектура становится готова к масштабированию и промышленному использованию.

Новая архитектурная парадигма

Clean Architecture

АРХИТЕКТУРА

Реализована строгая слоистая архитектура с инверсией зависимостей. Доменный слой не зависит ни от каких внешних фреймворков или библиотек.

# Структура Clean Architecture src/solepro/ ├── core/ # Ядро приложения (чистая бизнес-логика) │ ├── domain/ # Сущности, Value Objects, исключения │ ├── application/ # Use Cases, DTO, сервисы │ └── ports/ # Интерфейсы для внешних слоев ├── infrastructure/ # Реализации портов (SQLAlchemy, конфигурация) └── presentation/ # UI (Desktop PyQt6, Telegram Bot)
src/solepro/__init__.py - Основной пакет
src/solepro/core/ - Чистая архитектура ядра
src/solepro/infrastructure/ - Инфраструктурный слой
src/solepro/presentation/ - Презентационный слой

Промышленная БД: SQLAlchemy + PostgreSQL

ИНФРАСТРУКТУРА

Замена сырого SQLite3 на SQLAlchemy ORM с поддержкой PostgreSQL. Реализованы Alembic миграции, репозитории с паттерном Unit of Work.

from sqlalchemy import Column, DateTime, Float, String from sqlalchemy.ext.declarative import declarative_base Base = declarative_base() class TransactionModel(Base): __tablename__ = "transactions" id = Column(String(36), primary_key=True, default=uuid.uuid4) date = Column(DateTime, nullable=False) income = Column(Float, nullable=False, default=0.0) expense = Column(Float, nullable=False, default=0.0) tax = Column(Float, nullable=False, default=0.0)
src/solepro/infrastructure/database/models.py - SQLAlchemy модели
src/solepro/infrastructure/database/repositories/ - Репозитории
alembic/ - Миграции базы данных

DDD: Сущности и Value Objects

ДОМЕН

Иммутабельные доменные сущности с инвариантами. Value Objects для типовобезопасной работы с деньгами, датами и другими доменными концепциями.

@dataclass(frozen=True) class Transaction: id: UUID = field(default_factory=uuid4) date: datetime = field(default_factory=datetime.now) income: Money = field(default_factory=lambda: Money(0)) expense: Money = field(default_factory=lambda: Money(0)) tax: Money = field(default_factory=lambda: Money(0)) counterparty_id: Optional[UUID] = None def calculate_profit(self) -> Money: return self.income - self.expense - self.tax
src/solepro/core/domain/entities/transaction.py - Сущность транзакции
src/solepro/core/domain/value_objects/money.py - Value Object для денег
src/solepro/core/domain/exceptions/ - Доменные исключения

Инфраструктура и DevOps

Полная Docker-контейнеризация

DOCKER

Проект готов к развертыванию в Docker с поддержкой PostgreSQL, Redis и полной изоляцией окружений для разработки и продакшена.

# docker-compose.yml services: postgres: image: postgres:15-alpine environment: POSTGRES_DB: solepro_finance POSTGRES_USER: solepro_user POSTGRES_PASSWORD: ${DB_PASSWORD} redis: image: redis:7-alpine command: redis-server --appendonly yes app: build: . depends_on: - postgres - redis
docker-compose.yml - Основной Docker Compose
docker-compose.test.yml - Для тестового окружения
docker/app/Dockerfile - Dockerfile приложения

Профессиональная конфигурация

ИНФРАСТРУКТУРА

Централизованная система конфигурации через переменные окружения с поддержкой разных окружений (development, testing, production).

@dataclass class DatabaseConfig: url: str = field(default_factory=lambda: os.getenv( "DATABASE_URL", "sqlite:///./data/finances.db" )) pool_size: int = field(default_factory=lambda: int( os.getenv("DB_POOL_SIZE", "5") )) echo: bool = field(default_factory=lambda: os.getenv("DB_ECHO", "False").lower() == "true" )
src/solepro/infrastructure/config/__init__.py - Конфигурация приложения
pyproject.toml - Современная конфигурация Python проекта
requirements/ - Разделенные файлы зависимостей

Dependency Injection

АРХИТЕКТУРА

Внедрение DI контейнера для управления зависимостями между компонентами. Упрощение тестирования и конфигурации.

class Container(containers.DeclarativeContainer): # Конфигурация config = providers.Configuration() # Репозитории transaction_repository = providers.Factory( SQLAlchemyTransactionRepository, session=session_factory ) # Use Cases add_transaction_use_case = providers.Factory( AddTransactionUseCase, transaction_repository=transaction_repository, counterparty_repository=counterparty_repository )
src/solepro/infrastructure/di/__init__.py - DI контейнер
src/solepro/main.py - Точка входа с DI
