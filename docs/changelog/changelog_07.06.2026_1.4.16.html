Обзор

Скрипт обновления прод-версии подготовлен к использованию другими пользователями публичного репозитория: определение Python сделано устойчивым к разным окружениям (наличие/отсутствие py-лаунчера, конкретная минорная версия, работа из виртуального окружения).

Гибкое определение Python

PORTABILITY
  • Приоритет — виртуальное окружение проекта (.venv): если приложение в venv, зависимости ставятся именно туда
  • Иначе — системный Python 3.13+: py -3.13 → py -3 → python → python3 (с проверкой версии)
  • Если подходящий Python не найден — понятная ошибка вместо падения
  • RepoUrl по умолчанию указывает на публичный репозиторий; переопределяется параметром
# Поиск интерпретатора (упрощённо) .venv\Scripts\python.exe -> py -3.13 -> py -3 -> python -> python3 # берётся первый рабочий с версией >= 3.13

Совместимость и проверки

  • Парсинг прод-скрипта подтверждён под Windows PowerShell 5.1
  • Resolve-Python проверен: находит системный py -3.13 (Python 3.13.11) и .venv проекта
  • Ранее устранённые проблемы (BOM-кодировка, robocopy/chcp по полному пути) сохранены
  • Путь к проду по-прежнему авто-определяется; data-симлинк не обязателен
