Подробный отчет об изменениях интерфейса, настроек и интеграции параметров UI

Дата: 19.02.2026 Версия: 1.4.0 Формат: Подробный changelog Область: Desktop UI / Settings / Styling

1. Краткое резюме

Выполнен крупный пакет изменений UI-настроек и визуального поведения десктопного клиента. Основные результаты:

  • Исправлена заливка пустой области вертикального заголовка таблиц.
  • Окно Настройки переработано и переведено на вкладки для устранения проблемы переполнения по высоте.
  • Добавлен новый набор параметров в settings.ini (поведение окна, автообновление, цвета, размеры диалогов, размеры графиков).
  • Новые параметры интегрированы в MainWindow, StatisticsDialog, TransactionDialog, CounterpartyManagerDialog и таблицы.
  • Удалена устаревшая настройка totals_panel_height.

2. Исправления и рефакторинг UI

2.1 Вертикальные заголовки таблиц

Исправлен визуальный дефект: пустая область слева больше не заливается зеленым цветом. Цвет сохраняется только у реальных секций (строк с данными).

src/solepro/presentation/desktop/ui_settings.py

2.2 Окно Настройки: новая компоновка

Настройки сначала сгруппированы по тематическим блокам, затем окно переведено на вкладки:

  • Общие
  • Таблицы
  • Итоги
  • Расширенные

Добавлены поясняющие подписи в группах.

src/solepro/presentation/desktop/views/dialogs/settings_dialog.py

3. Новые настройки в settings.ini

Добавлены и подключены следующие ключи:

[ui] auto_refresh_enabled = 1 auto_refresh_interval_ms = 30000 main_window_pos_x = 100 main_window_pos_y = 100 main_window_width = 1400 main_window_height = 800 totals_income_color = #2e7d32 totals_expense_color = #c62828 totals_tax_color = #1565c0 totals_profit_positive_color = #2e7d32 totals_profit_negative_color = #c62828 totals_count_color = #666666 totals_card_border_color = #e0e0e0 dialog_transaction_min_width = 500 dialog_counterparty_manager_min_width = 900 dialog_counterparty_manager_min_height = 500 dialog_statistics_min_width = 800 dialog_statistics_min_height = 600 color_income = #2e7d32 color_expense = #c62828 color_tax = #1565c0 color_profit_positive = #2e7d32 color_profit_negative = #c62828 color_neutral = #666666 chart_monthly_min_height = 280 chart_concentration_min_height = 260 chart_tax_min_height = 250

Из конфигов удален legacy-ключ:

totals_panel_height
