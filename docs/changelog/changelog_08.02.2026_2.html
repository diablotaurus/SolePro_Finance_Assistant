Краткое резюме релиза

Версия 2.1.0 фокусируется на практическом использовании: исправлены ошибки запуска Desktop и Telegram, стабилизирована работа с SQLite, улучшены сценарии добавления операций, введены пользовательские настройки UI, переработаны фильтры и отображение итогов. Релиз ориентирован на повседневную работу без технических обходов и ручных вмешательств.

Ключевые изменения

Desktop

Интерфейс и навигация

  • Переработан блок фильтров: логика по умолчанию, сброс и «Показать все записи»
  • Панель фильтров скрывается по умолчанию, добавлен переключатель в меню
  • Добавлена верхняя строка итогов «Текущий период»
  • Исправлено отображение контрагентов и примечаний
  • Улучшена ширина и выравнивание карточек итогов
Telegram

Бот и диалоги

  • /help оформлен в виде полной инструкции
  • /add реализован как диалог с кнопками «Сегодня», контрагенты, «Да/Нет»
  • Постоянное меню: «Добавить» и «Статистика»
  • Исправлены импорты и подключения конфигов
  • Подготовлены запуск и вывод ошибок через bat/py
Инфраструктура

База и конфигурация

  • Корректная работа с относительным DATABASE_URL
  • SQLite: WAL + timeout для устойчивости
  • Репозитории делают commit при сохранении/удалении
  • Добавлен единый settings.ini для UI-настроек
  • Упорядочены импорты и init-пакеты
UX

Настройки и визуальный контроль

  • Регулировка шрифта номеров строк
  • Регулировка отступа высоты строки
  • Регулировка высоты панели итогов
  • Перекрытие глобального QSS для заголовка
  • Оптимизация запуска приложения

Telegram бот: улучшения

/help: подробная инструкция и список команд
/add: кнопка «Сегодня», выбор контрагентов из БД
Подтверждение «Да/Нет» через кнопки
Постоянные кнопки меню: «Добавить» и «Статистика»

Запуск бота через RunBot.bat с корректным PYTHONPATH

База данных и надежность

Автоматическое преобразование относительного DATABASE_URL в абсолютный путь
SQLite WAL + timeout для защиты от блокировок
Репозитории коммитят изменения (данные не пропадают)
init_db использует PYTHONPATH для стабильного запуска

Важно

Для переносимости проекта DATABASE_URL хранится в относительном виде. Абсолютный путь формируется на старте приложения автоматически.

Known Issues / Ограничения

Расширенная статистика (по месяцам, топ контрагентов) пока не реализована
Фильтрация выполняется в памяти после загрузки списка, на больших объемах это может влиять на скорость
Telegram бот работает в режиме polling (webhook не настроен)
Настройки UI из settings.ini применяются при запуске, требуется перезапуск
