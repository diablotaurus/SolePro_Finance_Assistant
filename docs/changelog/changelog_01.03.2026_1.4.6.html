Подробный changelog по задаче: улучшение UX настройки цветовых параметров Desktop UI
Дата: 01.03.2026
Версия: 1.4.6
Компонент: Desktop (PyQt6)
Статус: Выполнено и проверено

1. Цель изменений

Повысить удобство и наглядность редактирования HEX-цветов в окне "Настройки", не меняя бизнес-логику и формат хранения данных.

  • Сделать поля ввода цветов более компактными.
  • Добавить визуальный live-preview выбранного цвета рядом с полем ввода.
  • Унифицировать размеры полей между блоками "Карточки итогов: цвета" и "Цветовая палитра: семантика".
  • Сохранить текущую архитектуру MVC/OOP/DRY/SOLID и существующие ключи в settings.ini.

2. Что изменено в интерфейсе

  • В блоке "Карточки итогов: цвета" поля ввода стали компактными (единая узкая ширина для HEX).
  • В блоке "Карточки итогов: цвета" рядом с каждым полем добавлен квадрат превью цвета.
  • В блоке "Цветовая палитра: семантика" реализован такой же механизм превью.
  • Размер всех квадратов превью установлен: 30x30.
  • Размер полей ввода в обоих цветовых блоках выровнен для единообразного визуального оформления.
  • Минимальная ширина окна "Настройки" подтверждена на значении 600.

3. Техническая реализация

  • Добавлен универсальный хелпер для строки цвета: поле ввода + preview-квадрат.
  • Добавлен словарь соответствия поля и preview-виджета для централизованного обновления.
  • Обновление preview привязано к событию textChanged, работает в реальном времени.
  • При невалидном HEX в preview используется нейтральный fallback (#ffffff), при этом текущая валидация на сохранении сохранена без изменений.
  • Существующая логика чтения/сохранения настроек не изменялась.

  • pyproject.toml (обновление версии до 1.4.6)

  • Проверен размер preview: 30x30.
