Обзор релиза

После публикации проекта на GitHub добавлена непрерывная интеграция (CI): на каждый push в main и на каждый pull request автоматически запускаются все 156 тестов. Это защищает зелёный набор тестов от случайных регрессий. Попутно синхронизированы зависимости и зафиксировано правило разделения коммита и публикации.

Синхронизация зависимостей

DEPS

Файл requirements.txt приведён в соответствие с pyproject.toml: убран неиспользуемый loguru, добавлен pydantic-settings (используется dependency-injector в связке с pydantic v2).

requirements.txt — −loguru, +pydantic-settings

Проверка после публикации

GitHub Actions нельзя запустить локально — статус прогона CI будет виден только после push в репозиторий. Если headless-Qt в CI потребует дополнительных системных библиотек, конфигурация будет уточнена по результатам первого запуска.

Правила проекта

Правило 9: коммит ≠ push

DOCS

В AGENTS.md зафиксировано: по умолчанию выполняется только локальный git commit; git push на GitHub — лишь по явной отдельной просьбе. Ветка master (старая история с .env) никогда не публикуется.
