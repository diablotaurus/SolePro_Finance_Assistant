Область: Desktop UI / Settings
Автор: Diablotaurus

1. Цель изменений

Изменить компоновку настроек в desktop-окне "Настройки", чтобы структура стала более логичной по экранным зонам приложения, и устранить проблему, при которой на вкладке "Главное окно" переставали помещаться кнопки Save и Cancel.

Изменения выполнены без изменения бизнес-логики и без изменения ключей в settings/settings.ini.

  • Карточки итогов: цвета

Диалоги

2.2 Исправление проблемы с переполнением

Во вкладку "Главное окно" добавлен QScrollArea. Это гарантирует доступ к полям большой высоты и одновременно сохраняет фиксированную видимость кнопок Save/Cancel в нижней части диалога.

general_scroll = QScrollArea() general_scroll.setWidgetResizable(True) general_scroll.setWidget(general_content) general_tab_layout.addWidget(general_scroll)
