Единый модуль логирования

shared/logging_config.py

SHARED

Идемпотентная настройка корневого логгера: единый формат, консольный обработчик всегда, файловый — опционально (с созданием каталога). Повторные вызовы не плодят обработчики.

def setup_logging(level: str = "INFO", log_file: Optional[str] = None) -> None: # единый формат + консоль (+ файл, если задан) ... def get_logger(name: str) -> logging.Logger: ...

Desktop и Telegram-бот

PRESENTATION

Desktop: дефолтный log_writer переведён с print на logger.info (параметр остался инъектируемым), main() настраивает лог в logs/app.log. Бот: basicConfig заменён на общий setup_logging, все print() в баннере запуска заменены на logger.info.

src/solepro/presentation/desktop/application.py
src/solepro/presentation/telegram/bot.py

Политика вывода: бот логирует в консоль (он запускается в терминале), desktop — в файл logs/app.log (windowless .pyw). Механизм и формат — единые. Инъектируемый log_writer сохранён для тестируемости.

Попутно: устранён скрытый баг

shared/exceptions.py — отсутствовал импорт Any

В файле shared/exceptions.py аннотация Any использовалась в 4 местах, но from typing import Any отсутствовал — файл фактически не мог быть импортирован. Баг «спал», потому что пакет solepro.shared ранее нигде не подключался. Подключение нового shared/logging_config.py впервые запустило shared/__init__.py и выявило проблему. Добавлен недостающий импорт — минимальная необходимая правка.

src/solepro/shared/exceptions.py — добавлен from typing import Any
