Ключевые улучшения релиза

Выполнена серия точечных улучшений Desktop интерфейса, направленных на удобство ввода данных, единый визуальный стиль и корректность сортировки. Подключена глобальная иконка приложения, внедрена логика добавления контрагентов из окна транзакции, выровнены таблицы и заголовки, исправлена статистика.

Интерфейс и стиль

Единая обводка полей

UI

Добавлена корректная обводка для многострочных полей ввода в диалогах транзакций и контрагентов. Стиль приведен к единому виду с однострочными полями.

Нумерация строк

UI

В таблицах статистики, транзакций и контрагентов активирован вертикальный заголовок с нумерацией строк. Центрирование номеров и управляемая ширина задаются через settings.ini.

Визуальная гармония

UX

Вертикальные заголовки унифицированы по высоте строк и шрифту. Таблицы стали визуально ровными и единообразными.

Логика и функциональность

Добавление контрагента из транзакции

LOGIC

Из окна «Добавить транзакцию» теперь можно создать контрагента напрямую. Новый контрагент автоматически выбирается после сохранения.

Корректная сортировка

LOGIC

Сортировка по датам и суммам в таблице транзакций исправлена. Используется числовой и временной ключ, а не строковый текст.

Средний налог в статистике

LOGIC

Добавлен расчет среднего налога и корректное отображение нулевых значений без прочерков.

Иконка приложения

Иконка устанавливается глобально на уровне QApplication. Приоритет загрузки: solepro.ico → solepro.png → solepro.svg. Все окна получают иконку по умолчанию, при необходимости могут переопределять ее локально.
