1. Общий итог выполненной работы

В рамках этапного развития проекта были последовательно закрыты ключевые задачи по надежности хранения денежных данных, bootstrap-инициализации БД, снятию TODO в use-cases и усилению тестового контура.

Изменения внесены с сохранением MVC-слоев, разделением ответственности между presentation/application/infrastructure, и с обязательной фиксацией версии приложения в каждом коммите.

Технический фокус

  • Переход money-полей на Decimal/Numeric.
  • Согласование entrypoints desktop/telegram.
  • Seed-инициализация данных и DI wiring.
  • Покрытие bootstrap тестами качества.

Контроль качества

  • Добавлены и усилены тесты use-cases.
  • Добавлены проверки для init_db bootstrap.
  • Снижен риск регрессий при запуске приложения.
