Подробный отчет по изменениям: реорганизация desktop UI-слоя, окно настроек и централизация табличных шрифтов.

Дата: 18.02.2026 Отчет: changelog_18.02.2026_2 Версия: 1.3.10 RC Статус: Выполнено

1. Ключевой итог

Выполнен структурный рефакторинг desktop presentation-слоя: диалоги и виджеты разведены по отдельным подпакетам.

Добавлено окно Файл -> Настройки... с сохранением в settings/settings.ini, включая настройку шрифта и кегля табличной части всех окон.

2. Архитектурные изменения структуры (MVC/OOP/DRY/SOLID)

Новая структура UI

  • src/solepro/presentation/desktop/views/dialogs/ — все dialog-классы.
  • src/solepro/presentation/desktop/views/widgets/ — переиспользуемые виджеты.
  • src/solepro/presentation/desktop/main_window.py — композиция UI и wiring.

Переносы файлов (логические группы)

  • counterparty_dialog.py -> views/dialogs/counterparty_dialog.py
  • counterparty_manager.py -> views/dialogs/counterparty_manager_dialog.py
  • settings_dialog.py -> views/dialogs/settings_dialog.py
  • views/transaction_dialog.py -> views/dialogs/transaction_dialog.py
  • views/statistics_dialog.py -> views/dialogs/statistics_dialog.py
  • views/transaction_table.py -> views/widgets/transaction_table.py
  • views/filter_panel.py -> views/widgets/filter_panel.py

3. Изменения по функционалу

Окно настроек UI

  • Добавлено действие меню: Файл -> Настройки....
  • Создан диалог настройки параметров таблиц и UI-отступов.
  • Настройки сохраняются в UTF-8 через единый сервис DesktopUiSettings.

Табличные шрифты

  • Добавлены ключи: table_font_family, table_font_size, table_header_font_family, table_header_font_size.
  • Стиль таблиц/заголовков теперь собирается из settings/settings.ini.
  • Вертикальные заголовки таблиц тоже учитывают семейство шрифта.
