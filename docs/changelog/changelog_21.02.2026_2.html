Подробный отчет по переработке Desktop UI, расширению тестового покрытия и стабилизации статистических вкладок
Дата: 21.02.2026
Версия: 1.4.5
Область: Desktop UI / Statistics / QA
Автор: Diablotaurus

1. Краткое резюме релиза

Выполнена последовательная серия улучшений интерфейса и качества кода: переработано окно Настройки, исправлено непреднамеренное изменение числовых полей колесиком мыши, расширено тестовое покрытие по слоям presentation/infrastructure, обновлена аналитика окна Статистика с объединением вкладок контрагентов и добавлением сортировки по заголовкам таблицы.

2. Desktop UI: окно Настройки

2.1 Новая компоновка вкладок

Главное окно
  • поведение приложения и геометрия окна;
  • компоновка карточек итогов;
  • цвета карточек итогов.
Транзакции и таблицы
  • шрифты таблиц;
  • размеры/отступы вертикальных заголовков и колонок.
Статистика
  • семантическая цветовая палитра;
  • размеры графиков.
Диалоги
  • минимальные размеры диалоговых окон.

2.2 Исправление переполнения вкладки

Для длинной вкладки добавлен QScrollArea, благодаря чему кнопки Save/Cancel стабильно остаются видимыми внизу диалога.

2.3 Исправление wheel-поведения для QSpinBox

Добавлен специализированный spinbox-контрол, исключающий случайное изменение числовых параметров при простом наведении курсора и вращении колеса мыши.

- отключен wheel-focus (StrongFocus) - блокировка wheelEvent без фокуса - фильтр wheel-событий на внутреннем lineEdit

3. Окно Статистика: контрагенты

3.1 Переработка аналитики

Вкладки Топ контрагентов и Портфель контрагентов объединены в одну вкладку Топ контрагентов.

  • Добавлен блок Метрики портфеля (активные контрагенты, средняя маржа, лучший по прибыли, медианная прибыль).
  • Сохранена расширенная информативность таблицы: доход/расход/налог/прибыль/маржа/транзакции.
  • Сохранено ранжирование контрагентов как в классическом топе (исходный порядок набора статистики).

3.2 Сортировка по заголовку таблицы

Для таблицы на вкладке Топ контрагентов включена сортировка по клику на заголовок. Для денежных и процентных столбцов реализована корректная числовая сортировка через специализированный item-класс.

4. Тестовое покрытие

4.1 P0 тесты (критическое UI/поведение)

  • test_settings_dialog_behavior.py — wheel/focus/скролл и видимость кнопок в настройках;
  • test_desktop_ui_settings.py — DesktopUiSettings и TableUiConfigurator;
  • test_access_middleware.py — ветки Telegram AccessMiddleware.

4.2 P1 тесты (инфраструктура и сервисы)

  • test_transaction_export_service.py — экспорт Excel, формат данных, ширины колонок;
  • test_config_parsing.py — env-парсинг и нормализация конфигурации;
  • test_migrations_module.py — ветки миграций и fallback stamp;
  • test_session_manager.py — commit/rollback/close/session lifecycle.

4.3 P2 тесты (presentation wiring)

  • test_filter_panel.py — сбор фильтра, show_all/clear, маппинг типов и сумм;
  • test_telegram_setup_handlers.py — регистрация Command/Message/Conversation handler-ов.

5. Обновления зависимостей и стабильность

  • Обновлен baseline зависимости openpyxl до >=3.1.5 в pyproject.toml и requirements.txt.
  • Проведены таргетные и полные прогоны тестов (pytest src/tests -q) с успешным завершением.
  • Оставшиеся предупреждения связаны с внутренним кодом openpyxl (DeprecationWarning), не с кодом проекта.

7. Итог

Релиз концентрируется на практичности UI для ежедневной работы, предотвращении пользовательских ошибок ввода, улучшении аналитики по контрагентам и системном расширении автоматических тестов. Изменения выполнены с сохранением совместимости существующих настроек и текущих точек входа приложения.
